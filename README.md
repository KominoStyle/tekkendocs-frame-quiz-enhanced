# TekkenDocs Frame Quiz Enhanced

A userscript that improves the Tekken 8 Frame Quiz on TekkenDocs for more precise frame-data training.

## Features

- Exact punish-frame answers from -10 to -15
- Separate -16 or worse category
- Configurable safe-frame training
- Automatic progression between questions
- Visual correct / incorrect answer feedback
- Stops the previous move from looping after answering
- Works with TekkenDocs SPA navigation

## Install

### Requirements

Install a userscript manager such as Tampermonkey.

### Install from GitHub

[Install userscript](https://raw.githubusercontent.com/KominoStyle/tekkendocs-frame-quiz-enhanced/main/tekkendocs-frame-quiz-enhanced.user.js)

Then confirm the installation in Tampermonkey.

## Usage

Open:

https://tekkendocs.com/t8/framequiz

Start a Frame Quiz normally.

The enhanced answer buttons will automatically replace the default answer choices.

Press F8 to switch between the available safe-frame training modes.
